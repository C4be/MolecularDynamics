# Molecular Dynamics

**Описание проекта:**
Это проект молекулярной динамики, который моделирует взаимодействие частиц в системе. Основные компоненты:
- Класс Particle для представления частиц с позицией, скоростью и силами
- Класс System для управления коллекцией частиц и расчетов
- Параметры системы в constants.h и params.h
- Используется алгоритм Верле для интегрирования

**Что делает проект:**
1. Моделирует движение частиц в 3D пространстве
2. Рассчитывает взаимодействия между частицами (потенциал Леннард-Джонса)
3. Выполняет численное интегрирование для обновления состояний частиц

**Требования для установки:**
1. CMake версии 3.26 или выше
2. Компилятор C++ с поддержкой стандарта C++17
3. Система сборки (make, ninja и т.д.)

**Как запустить проект:**
1. Создать папку для сборки:
```bash
mkdir build && cd build
```

2. Сгенерировать проект:
```bash
cmake ..
```

3. Собрать проект:
```bash
cmake --build .
```

4. Запустить программу:
```bash
./MolecularDynamics
```

**Текущее состояние:**
- Основная программа (main.cpp) содержит только тестовый вывод
- Необходимо реализовать основную логику симуляции
- В System.cpp есть TODO для доработки расчета сил

Для полноценной работы проекта потребуется доработать main.cpp для:
1. Инициализации системы частиц
2. Организации временного цикла симуляции
3. Вывода результатов
